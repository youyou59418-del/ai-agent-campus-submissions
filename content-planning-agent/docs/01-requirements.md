# 用户、目标、范围和成功标准

## 业务目标

运营人员提供主题、预算和截止时间，希望得到可确认的内容活动方案，而不必在工具失败和成本变化后手工重新计算。系统输出任务依赖、每步实际状态、工具结果、已花费用合计及已保存方案，无法完成则说明原因与缺口。

合成素材库和工具费用表随仓库交付。活动方案包括目标、受众/渠道假设、脚本和素材清单；未提供的受众与渠道明确标为假设，未编造效果数据。素材检索与脚本生成是本地合成工具，真实模型负责工具动作选择与重规划。

## 范围

CLI 是唯一必需运行入口。支持一个请求的两种成本方案、预算和截止时间硬约束、步骤依赖、模拟故障、部分成功、幂等和故障续跑。不做界面、发布、真实视频生成、真实资金支付或生产 Runtime。

premium 和 economy 是两个可解释的计划模板，模型在约束下选择，并非声称模型能自由创造任意工作流。预设依赖骨架符合考核允许的范围；观察后选择替代方案、重试或结束必须由模型发起。

## 必验与扩展标准

| 要求 | 可检查的成功标准 | 实际材料 |
|---|---|---|
| 正常完成 | 成功检索、生成、再估算和保存；费用及依赖正确 | examples/live/normal/ |
| 缺预算/截止时间 | NEEDS_INPUT，明确缺字段；零模型调用、零业务费用 | missing_budget/、missing_deadline/、missing_both/ |
| 工具失败 | 保留成功素材和 FAILED 尝试；模型决定重试/替代或停止 | tool_failure/、permanent_failure/ |
| 预算超限 | 工具返回 12 不可行后，模型改选 8，再估算并保存 | budget_replan/ |
| 无可行预算 | 不花费不可行方案的工具费用，返回最小缺口 | budget_impossible/ |
| 重复执行 | 相同方案 ID、相同账本，不重复成功业务步骤或收费 | duplicate/ 两轮 |
| 失败续跑 | 同数据库恢复，旧尝试完整保留，未重做检索，合计费用正确 | resume/ 两轮 |
| 部分成功 | PARTIAL 子结果保留，可满足 economy 依赖；不伪造成功 | partial_success/ |
| 截止时间约束 | premium 太慢时选 economy；都太慢时返回时间缺口 | deadline_replan/、deadline_impossible/ |
| 保存失败 | 脚本与素材保留，保存结果不冒充成功 | save_failure/ |
| 执行上限 | 预算耗尽或步骤上限时明确 INCOMPLETE，不无限循环 | step_limit/ |

表中省略前缀的路径均位于 examples/live/。同名 examples/mock/ 是离线流程材料，来源和作用不同。真实模式 15 组验收包含 3 组确定性的缺参前置检查；其余 12 组实际调用模型。

## 不可越过的边界

预算和截止时间来自原始输入，模型工具不接收覆盖参数。费用由费用表和真实执行尝试计算，不由模型填写。失败或部分结果不被删除或改写成成功。已成功步骤缓存复用；相同请求 ID 携带不同要求直接拒绝。

截止时间依据合成工具分钟验证；业务模拟单位与真实模型 token/账单完全分离。当前合成实验不能证明真实内容质量、活动效果或实际交付时效。
